## 🎯 Project Overview
AI system for detecting vehicles using YOLOv11 and a Streamlit web interface.

---

## ⚙️ Tech Stack
- Python  
- YOLO (Ultralytics)  
- OpenCV  
- Streamlit  

---

## ✨ Features
- Upload image and detect vehicles  
- Real-time inference  
- Adjustable confidence threshold  
- Annotated results display  

---

## 📁 Dataset Classes
- car  
- truck  
- bus  
- motorcycle  
- bicycle
